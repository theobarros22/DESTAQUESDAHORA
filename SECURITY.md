# Relato de problemas de segurança

Se você encontrou uma falha de permissão, vazamento de chaves, injeção ou qualquer outro problema que possa afetar a segurança de uma instalação, entre em contato com os mantenedores pelo [relato privado de vulnerabilidades do GitHub](https://github.com/theobarros22/DESTAQUESDAHORA/security/advisories/new).

Informe:

- a versão (commit) afetada, a forma de instalação e os dados de ambiente necessários;
- os passos mínimos para reproduzir o problema em um ambiente que você tem autorização para testar;
- o impacto possível e logs ou capturas de tela com os dados sensíveis removidos.

Não divulgue detalhes exploráveis da falha em Issues, discussões ou PRs públicos, e não envie chaves reais, senhas, cookies, dados de usuários ou o banco de dados completo. Dúvidas de uso e bugs que não sejam de segurança devem ir para as [Issues](https://github.com/theobarros22/DESTAQUESDAHORA/issues/new/choose).

Hoje, os problemas de segurança são verificados e corrigidos primeiro na versão mais recente da branch `main` do repositório público; não há uma branch de suporte de longo prazo mantida à parte. Os mantenedores confirmam o alcance do problema, preparam a correção e publicam um aviso no momento adequado; não há prazo de resposta garantido por enquanto.
